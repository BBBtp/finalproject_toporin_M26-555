# ValutaTrade Hub: финальный проект

## Цель

Консольный учебный симулятор торговли валютами для зарегистрированных пользователей. Балансы хранятся локально в JSON. При покупке средства списываются с USD-кошелька, пополняемого командой `deposit --amount`; при продаже USD начисляются обратно.

## Поведение

- Регистрация создаёт пользователя и пустой портфель. Пароль хранится как солёный хеш, сессия существует только во время запуска CLI.
- `deposit` пополняет USD; `buy` и `sell` атомарно меняют два кошелька после проверки курса, положительной суммы и достаточного баланса.
- Курсы выражены в USD за единицу валюты. Поддержаны USD, EUR, GBP, RUB, BTC, ETH, SOL. Цена кросс-пары A/B вычисляется как (USD за A) / (USD за B).
- `get-rate` и сделки требуют свежего курса в пределах TTL. Обновление выполняется явно через `update-rates`; при отсутствии или устаревании курса выводится понятная ошибка.
- Crypto курсы берутся из CoinGecko, fiat из ExchangeRate-API. Для fiat нужен `EXCHANGERATE_API_KEY`. Если один API недоступен, другой источник всё равно сохраняется.
- `show-rates` показывает кеш с фильтрами. История обновлений хранится отдельно. Ошибки не приводят к частично выполненной сделке.
- В CLI доступны `register`, `login`, `deposit`, `show-portfolio`, `buy`, `sell`, `get-rate`, `update-rates`, `show-rates`, `help`, `exit`. Для долгой сессии команды вводятся в интерактивном режиме; отдельная команда через аргументы также поддерживается.

## Хранение и модули

`core` содержит типы валют, модели и бизнес-правила; `infra` — настройки и атомарное JSON-хранилище; `parser_service` — HTTP-клиенты, нормализацию и историю курсов; `cli` — разбор и вывод команд. Состояние располагается в `data/`, ключ API читается из окружения. Денежные значения представляются `Decimal` и сериализуются строками.

## Проверка

Автономные тесты проверяют регистрацию, вход, deposit, покупку, продажу, нехватку средств, недействительные суммы, свежесть и кросс-курсы, частичный отказ API, CLI-вывод. Ручной сценарий демонстрирует команды без обращения к внешним сервисам через фикстурные курсы.

## Ограничения

Это учебный симулятор: `deposit` добавляет виртуальные доллары, реальных платежей и ордеров нет. Нет серверной многопользовательской конкурентности. Демозапись может быть создана локально; публичная публикация только по отдельной просьбе.
